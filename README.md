# CampusOS.AI | Intelligent Student Living

CampusOS.AI is a sophisticated, AI-powered campus management platform designed to streamline hostel operations and enhance the student experience through intelligent automation and a modern "Liquid Glass" interface.

## 🚀 Key Features

### For Students
- **Smart Rent Tracking**: View monthly dues with AI indicators for market-rate fairness (Right Rent vs. Overpaying).
- **AI Matchmaker**: A natural-language search tool that matches student requirements (e.g., "quiet, near gym") with available room descriptions.
- **Lost & Found Hub**: AI-powered item reporting. Upload a photo, and the system automatically generates descriptions and matches lost items with found ones using location and timestamps.
- **Complaint Management**: Raise tickets that are automatically categorized and prioritized by AI based on urgency.

### For Administrators
- **Financial Analytics**: Comprehensive rent dashboard with bar charts visualizing revenue distribution (Paid, Pending, Overdue).
- **Room Management**: AI-assisted room posting. Owners get suggested market prices based on room amenities and descriptions.
- **Intelligent Triage**: Automated ticketing system that sorts maintenance, safety, and personal issues for faster resolution.

## 🎨 Design Language
- **Theme**: High-fidelity Dark Mode.
- **Aesthetic**: Liquid Glass (glassmorphism) with backdrop blurs and glowing decorative orbs.
- **Navigation**: Ergonomic bottom-docked navigation bar for a "mobile-first" feel on all devices.

## 🛠️ Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS + ShadCN UI
- **AI/GenAI**: Genkit 1.x with Google Gemini 2.5 Flash
- **Icons**: Lucide React
- **Charts**: Recharts
