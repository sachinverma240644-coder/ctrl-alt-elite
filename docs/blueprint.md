# **App Name**: DormDeck

## Core Features:

- AI-Powered Priority Triage: This tool uses reasoning to automatically categorize student tickets and assign a priority level based on the urgency described in the complaint text.
- Student Ticket Portal: Interface for students to raise issues including Title, Description, Hostel/Block, and Room Number with real-time submission tracking.
- Admin Statistics Dashboard: A high-level overview for admins to monitor KPIs such as Total Complaints, Pending, Resolved, and High-Priority tickets at a glance.
- Lost and Found Hub: A integrated community board within the application where users can report lost items or log found belongings for student recovery.
- Centralized Ticket Management: Admin panel to manage all tickets with searchable fields including Ticket ID, Category, Priority, and Status toggles.
- Dual-Role Access Control: A secure login system that routes users to either the Student panel or Admin panel based on their authenticated credentials.

## Style Guidelines:

- Primary color: Deep Indigo (#4361EE) chosen to evoke a sense of modern professional infrastructure and organized management.
- Background color: Glacial Mist (#F8F9FF), a highly desaturated blue hue providing a crisp, focused environment for data-heavy views.
- Accent: Sea Blue (#1A759F), an analogous tone used to highlight primary actions and status changes without distracting the user.
- Primary Font: 'Inter' is used for both headlines and body text to maintain an objective, technical look suitable for utility-focused management software.
- Utilize a minimal line-based icon set (2px weight) that aligns with the machined look of the typography and primary color.
- Embrace a grid-based dashboard layout with clearly defined card components for admin metrics and vertical stacking for student forms.
- Smooth 200ms ease-in transitions for dashboard card updates and subtle scale-up effects on interactive table rows.
